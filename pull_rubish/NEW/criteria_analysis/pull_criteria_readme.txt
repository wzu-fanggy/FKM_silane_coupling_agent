FKM-SiO2 踢出梯度双判据重算说明 (15-29 A/ps)
============================================

输入
----
轨迹: F:\Lammps-MS\FKM-SIO2-TEST\pull\NEW\kick_{15,17,19,21,23,25,27,29}Aps_traj.dump
初始构象: F:\Lammps-MS\FKM-SIO2-TEST\pull\NEW\pull_equil.data
每组 16000 步, dt = 0.5 fs, 共 8 ps, 每 0.5 ps 一帧。

计算方法
--------
1) 最小距离判据
   对每一帧计算 SiO2(type 7/8/9) 任意原子与 FKM(type 1-6) 任意原子的
   最小距离。x/y 采用周期性最小镜像, z 用解卷坐标。
   严格判据: dmin > 15.5 A (等于非键截断)。

2) 界面相互作用判据
   用 LAMMPS rerun 回放轨迹, compute group/group 输出 FKM-SiO2 的
   非键相互作用能 E_gg (pair + kspace), 逐帧读取。
   严格判据: |E_gg| < max(1 kcal/mol, 初始值 3%)。

3) 持续判据
   两个严格判据同时满足, 且连续 1 ps (至少 3 帧) 才记为"脱出"。

结论
----
1) 按"彻底脱出"的严格标准 (dmin > 15.5 A 且界面能降到初始 3% 以下),
   15-29 A/ps 全部不满足, 因为始终有 FKM 链段吸附在 SiO2 上。
   这与肉眼观察一致, 尤其底部吸附链始终存在。

2) 速度越高, 主体分离越明显:
   27 和 29 A/ps 的末帧 zsep 达到 65.5 和 70.6 A, 界面能降到初始约 19-20%,
   3.5 A 直接接触原子从约 1150 降到 400-445。

3) 建议论文措辞:
   不要写"彻底拔出", 改为"主体拔出/界面能衰减":
   15-25 A/ps 仅发生部分界面松脱; 27-29 A/ps 实现主体拔出,
   但残余链段吸附和长程静电使界面能无法归零。
